# Morozka 2.0 - Messenger

Лёгкий и простой мессенджер с поддержкой чата в реальном времени и видеозвонков.

## Технологии
- **Backend**: Node.js, Express, Socket.IO, SQLite
- **Frontend**: React, TypeScript, WebRTC (simple-peer), Framer Motion

## Как запустить локально

1. **Клонируйте репозиторий** (или просто перейдите в папку проекта).
2. **Установите зависимости** во всех папках:
   ```bash
   npm run install-all
   ```
   *Примечание: это установит зависимости для корня, клиента и сервера.*
   
3. **Запустите проект**:
   ```bash
   npm run dev
   ```
   *Эта команда запустит одновременно сервер (порт 3001) и клиент (порт 5173).*

4. **Откройте браузер**:
   Перейдите по адресу [http://localhost:5173](http://localhost:5173).

## Использование
- Создайте аккаунт на странице регистрации.
- Войдите в систему.
- Для проверки чата и звонков откройте вторую вкладку инкогнито и создайте другого пользователя.
- Нажмите на "Demo User" (ID: 1) или используйте ID другого пользователя для общения.

## Структура проекта
- `/server`: API на Express, база данных SQLite (`morozka.db`), логика Socket.IO.
- `/client`: React приложение с Vite, компоненты для чата и WebRTC звонков.
